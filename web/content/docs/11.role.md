---
title: Role
description: Role global (template platform) dan role custom milik company.
---

Role adalah kumpulan permission dalam **satu solution**. Ada tiga jenis (`scope` di respons):

| `scope` | Dibuat oleh | Berlaku di | Bisa diubah |
|---|---|---|---|
| `system` | Platform | Semua company | Tidak |
| `global` | Platform admin | Semua company | Ya, oleh platform admin |
| `company` | Member company / token service | Hanya company pemilik | Ya, oleh company pemilik |

Role global cocok untuk role standar solution (mis. `admin`, `staff`, `viewer`). Role custom dipakai bila
company butuh kombinasi permission sendiri.

`code` role: huruf kecil, angka, `_`, `-`, diawali huruf (mis. `hr-manager`), maks 100.

::note
Membuat, mengubah, menghapus, dan mengatur permission **role custom** dengan token user butuh permission
platform `role.manage` (lihat [permission platform](/docs/arsitektur-integrasi#permission-platform)). Solution **console** juga punya role:
role sistem `company_admin` dan role custom berisi permission platform. Role console hanya bisa dikelola
oleh pemegang **seluruh** permission platform, agar tidak ada eskalasi hak.
::

## Bentuk data

```json
{
  "id": "5e0b...",
  "solution_id": "6f1c0a52-...",
  "company_id": null,
  "code": "hr-manager",
  "name": "HR Manager",
  "description": "Kelola data karyawan",
  "is_system": false,
  "scope": "global",
  "created_at": "...",
  "updated_at": "...",
  "permission_count": 4,
  "member_count": 12
}
```

`company_id` terisi untuk role custom. Dalam konteks company, `member_count` hanya menghitung pemegang di
company tersebut.

## Role global

| Method & path | Siapa |
|---|---|
| `GET /api/v1/solutions/{solutionId}/roles` | Token apa pun. Query: `kind` (`global` / `custom`), `search`, pagination |
| `GET /api/v1/roles/{roleId}` | Token apa pun (role custom hanya untuk company pemilik, selain itu `404`) |
| `GET /api/v1/roles/{roleId}/permissions` | Token apa pun (aturan sama) |
| `POST /api/v1/solutions/{solutionId}/roles` | Platform admin |
| `PATCH /api/v1/roles/{roleId}` | Platform admin — `name`, `description` |
| `DELETE /api/v1/roles/{roleId}` | Platform admin — soft delete, semua assignment ikut dihapus |
| `PUT /api/v1/roles/{roleId}/permissions` | Platform admin — replace-all permission |

## Role custom company

Token user (member aktif, `cid` = company) atau token service ber-scope `roles:write`. Token service hanya
bisa memakai `solutionId` miliknya.

| Method & path | Keterangan |
|---|---|
| `GET /api/v1/companies/{companyId}/solutions/{solutionId}/roles` | Role global **dan** custom milik company — pakai ini untuk pilihan role di UI |
| `POST /api/v1/companies/{companyId}/solutions/{solutionId}/roles` | Buat role custom |
| `GET /api/v1/companies/{companyId}/roles/{roleId}` | Detail (global atau custom milik company) |
| `GET /api/v1/companies/{companyId}/roles/{roleId}/members` | Pemegang role di company |
| `PATCH /api/v1/companies/{companyId}/roles/{roleId}` | Ubah `name`, `description` (hanya custom) |
| `DELETE /api/v1/companies/{companyId}/roles/{roleId}` | Hapus role custom + semua assignment-nya |
| `PUT /api/v1/companies/{companyId}/roles/{roleId}/permissions` | Replace-all permission (hanya custom) |

Membuat role custom:

```bash
curl -X POST "$PLATFORM/api/v1/companies/$COMPANY_ID/solutions/$SOLUTION_ID/roles" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"code": "payroll-officer", "name": "Petugas Payroll", "description": "Menjalankan payroll"}'
```

Role global atau milik company lain yang dipakai di endpoint tulis custom → `404`.

## Mengatur permission role

**Replace-all**: daftar yang dikirim menjadi seluruh permission role.

```bash
curl -X PUT "$PLATFORM/api/v1/companies/$COMPANY_ID/roles/$ROLE_ID/permissions" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"permission_codes": ["employee.read", "payroll.run"]}'
```

Respons berisi permission role setelah perubahan:

```json
{
  "data": [
    { "id": "c0f1...", "code": "employee.read", "name": "Lihat karyawan", "status": "active" },
    { "id": "c0f2...", "code": "payroll.run", "name": "Jalankan payroll", "status": "active" }
  ]
}
```

| Kondisi | Respons |
|---|---|
| Code tidak ada di katalog solution role | `422` |
| Code disebut dua kali | `422` |
| Menambahkan permission `deprecated` | `422` (yang sudah terpasang boleh tetap dikirim) |
| Role sistem | `403` |

Kirim `"permission_codes": []` untuk mengosongkan permission role.
